Tạo web thành app

Điền tên app, link web và chọn ảnh icon, trang này sẽ tự tạo file cấu hình (.mobileconfig) dạng Web Clip toàn màn hình, mở app sẽ không hiện thanh địa chỉ như Safari. Trang chạy hoàn toàn trên máy của anh, không gửi tên, link hay ảnh lên máy chủ nào.

Tên này sẽ hiện dưới icon ngoài màn hình chính, viết có dấu, có cách bình thường.
Nếu anh nhập thiếu https:// thì trang sẽ tự thêm vào, vì link trong file cấu hình bắt buộc phải đầy đủ.
Nên dùng ảnh vuông cho đẹp. Trang sẽ tự cắt vuông và đổi về 512 x 512, định dạng PNG.
Chưa chọn ảnh thì file vẫn cài được, iOS sẽ tự lấy icon của web.
Anh xóa đi nếu không muốn ghi tổ chức vào file.

Mỗi lần bấm Tạo, trang sẽ sinh 2 UUID mới hoàn toàn và mã identifier mới từ tên app, nên không trùng với app đã cài trước đó. Anh chỉ cần tải file mới nhất cho mỗi app.

Nếu bấm Tạo lại, UUID sẽ đổi mới, anh dùng file mới nhất vừa tải, đừng cài file cũ chưa cài.

Cách cài sau khi tải

  1. Mở trang này bằng Safari, bấm Tạo rồi bấm Tải file.
  2. Nếu Safari không tự mở màn hình cài đặt, anh mở app Tệp, vào mục Tải về, bấm vào file .mobileconfig vừa tải.
  3. Vào Cài đặt, Cài đặt chung, VPN và Quản lý thiết bị, bấm vào cấu hình vừa tải.
  4. Bấm Cài đặt, nhập mật khẩu iPhone nếu máy hỏi, rồi xác nhận Cài đặt lần nữa.
  5. Icon sẽ hiện ngoài màn hình chính, bấm vào là mở web toàn màn hình.

Muốn gỡ app thì vào lại đúng màn hình cấu hình đó và bấm Xóa cấu hình, icon sẽ mất theo. Muốn dùng lại trang này lần sau cho nhanh, anh mở trang này bằng Safari rồi bấm Chia sẻ, Thêm vào Màn hình chính.
