# Tạo web thành app

Trang web tạo file cấu hình (.mobileconfig) dạng Web Clip toàn màn hình cho iPhone, không cần phím tắt.

Mở trang này bằng Safari, điền tên app hiển thị, link web và chọn ảnh icon, bấm Tạo rồi tải file .mobileconfig về và cài đặt. Mỗi lần bấm Tạo, trang tự sinh mã identifier từ tên app (bỏ dấu, bỏ cách) và sinh 2 UUID mới hoàn toàn, nên không trùng với app đã cài trước đó.

Trang chạy hoàn toàn trên trình duyệt, không gửi tên, link hay ảnh lên máy chủ nào.

## Cách cài sau khi tải file

1. Mở app Tệp, vào mục Tải về, bấm vào file .mobileconfig vừa tải.
2. Vào Cài đặt, Cài đặt chung, VPN và Quản lý thiết bị, bấm vào cấu hình vừa tải.
3. Bấm Cài đặt, nhập mật khẩu iPhone nếu máy hỏi, rồi xác nhận Cài đặt lần nữa.
4. Icon sẽ hiện ngoài màn hình chính, bấm vào là mở web toàn màn hình, không hiện thanh địa chỉ như Safari.
5. Muốn gỡ app thì vào lại đúng màn hình cấu hình đó và bấm Xóa cấu hình.
